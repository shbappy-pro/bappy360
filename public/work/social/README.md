# সোশ্যাল মিডিয়া ডিজাইন এখানে রাখুন

এই ফোল্ডারে ছবি আপলোড করলে Vercel deploy-এর সময় সেগুলো নিজে থেকেই সাইটের গ্যালারিতে যোগ হয়ে যায়।
`index.html` বা অন্য কোনো কোড বদলাতে হবে না।

## ফোল্ডারের নিয়ম

```
work/social/
  ecommerce/                 ← ক্যাটাগরি (ফিল্টার বাটনের নাম হবে "Ecommerce")
    flash-sale-banner.jpg
    lubdok/                  ← ব্র্যান্ড (ঐচ্ছিক, সার্চে খুঁজে পাওয়া যাবে)
      top-eid-campaign.jpg   ← নাম "top-" দিয়ে শুরু হলে হোমপেজে সবার আগে দেখাবে
  healthcare/
    CMH-Hospital/            ← বড় হাতের অক্ষর থাকলে নামটা হুবহু থাকবে
      world-health-day.jpg
  motion/
    product-reel.mp4         ← ভিডিও চলবে
    product-reel.jpg         ← একই নামের ছবি থাকলে সেটা ভিডিওর কভার হবে
```

- **ক্যাটাগরি:** `work/social/`-এর ভেতরের প্রথম ফোল্ডার। যেমন: ecommerce, healthcare, fashion, food, festival, real-estate, motion।
- **ব্র্যান্ড:** ক্যাটাগরি ফোল্ডারের ভেতরে আরেকটা ফোল্ডার দিলে সেটা ব্র্যান্ডের নাম হবে। দেওয়া বাধ্যতামূলক না।
- **টাইটেল:** ফাইলের নাম থেকেই হয়। `eid-mubarak-campaign.jpg` লিখলে দেখাবে "Eid mubarak campaign"। `IMG_2045.jpg`-এর মতো নাম হলে শুধু ক্যাটাগরির নাম দেখাবে।
- **ফরম্যাট:** JPG, PNG, WebP, GIF, AVIF, আর ভিডিওর জন্য MP4/WebM।
- **যেকোনো সাইজ চলবে:** 1:1, 4:5, 9:16, 16:9 সব নিজে থেকে গ্যালারিতে ঠিকঠাক বসে যায়।

## আপলোডের আগে ছবি ছোট করুন (জরুরি)

১০০০+ ছবি থাকবে, তাই প্রতিটা ছবি **চওড়ায় 1080px** আর **৩০০KB-এর নিচে** রাখুন।

- Photoshop: Export As → JPG, Quality 80, Width 1080
- অনেক ছবি একসাথে ছোট করতে: https://squoosh.app বা https://imagecompressor.com

## আপলোড করবেন যেভাবে

**অল্প ছবি হলে (GitHub ওয়েবসাইট দিয়ে):**
1. repo-তে `public/work/social/` ফোল্ডারে যান
2. **Add file → Upload files** চাপুন
3. কম্পিউটার থেকে পুরো ক্যাটাগরি ফোল্ডারটা (যেমন `healthcare`) টেনে এনে ছেড়ে দিন। ফোল্ডারের গঠন ঠিক থাকবে।
4. **Commit changes** চাপুন। ১-২ মিনিটের মধ্যে সাইটে চলে আসবে।

GitHub ওয়েবসাইট দিয়ে একবারে সর্বোচ্চ ১০০টা ফাইল আপলোড করা যায়।

**অনেক ছবি হলে (GitHub Desktop, ফ্রি):**
1. https://desktop.github.com থেকে ইনস্টল করে repo-টা clone করুন
2. কম্পিউটারের ফোল্ডারে `public/work/social/`-এর ভেতর ছবিগুলো কপি করুন
3. GitHub Desktop-এ **Commit** দিয়ে তারপর **Push** দিন

এভাবে ১০০০টা ছবিও একবারেই চলে যাবে।

## কোনো ছবি গ্যালারিতে না এলে

- ছবিটা সরাসরি `work/social/`-এ রাখলে আসবে না। অবশ্যই কোনো একটা ক্যাটাগরি ফোল্ডারের ভেতরে রাখতে হবে।
- Vercel → Deployments → সর্বশেষ deployment → **Build Logs**-এ `[gallery] 1240 designs in 8 categories` লাইনটা দেখুন। সেখানে মোট কয়টা ডিজাইন ধরা পড়েছে বোঝা যাবে।
