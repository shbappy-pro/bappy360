# UI/UX ডিজাইন এখানে রাখুন

প্রতিটা প্রজেক্টের জন্য একটা ফোল্ডার বানিয়ে তার ভেতরে স্ক্রিনগুলো রাখুন।
Vercel deploy-এর সময় সাইট নিজেই প্রজেক্ট কার্ড আর সব স্ক্রিনের পাতা বানিয়ে নেয়।
কোনো লেখা বা কেস স্টাডি লাগবে না, `index.html`-ও বদলাতে হবে না।

## ফোল্ডারের নিয়ম

```
work/ui/
  01-Pocket-Wallet/              ← প্রজেক্ট (নামের আগের নম্বর দিয়ে ক্রম ঠিক হয়, নম্বরটা সাইটে দেখায় না)
    01-home.png                  ← স্ক্রিন, নামের ক্রমে দেখায়। "home" নামটা স্ক্রিনের ক্যাপশন হবে
    02-cards.png
    03-insights.png
  02-Velvet-Store/
    desktop/                     ← ওয়েবসাইটের স্ক্রিন (ব্রাউজার ফ্রেমে দেখাবে)
      home.jpg
      product.jpg
    mobile/                      ← মোবাইলের স্ক্রিন (ফোন ফ্রেমে দেখাবে)
      home.jpg
      cart.jpg
    cover.jpg                    ← ঐচ্ছিক: কার্ডে এই ছবিটা দেখাবে (Dribbble শটের মতো মকআপ)
    info.txt                     ← ঐচ্ছিক: প্রজেক্টের তথ্য
```

- **ফোন না ব্রাউজার:** সাইট ছবির মাপ দেখে নিজেই বুঝে নেয়। সরু-লম্বা ছবি ফোন ফ্রেমে যায়, চওড়া ছবি ব্রাউজার ফ্রেমে। ভুল হলে স্ক্রিনগুলো `desktop/` আর `mobile/` নামের ফোল্ডারে আলাদা করে রাখুন।
- **কার্ডের ছবি:** `cover.jpg` না দিলে সাইট নিজেই প্রথম স্ক্রিনগুলো দিয়ে ফোন বা ব্রাউজারের মকআপ বানায়। লম্বা ওয়েবসাইট পাতা হলে মাউস রাখলে পাতাটা ওপর থেকে নিচে স্ক্রল হয়।
- **প্রজেক্টের নাম:** ফোল্ডারের নাম থেকে হয়। `02-Velvet-Store` লিখলে দেখাবে "Velvet Store"।

## info.txt (ঐচ্ছিক)

```
type: Dashboard
year: 2025
tools: Figma, FigJam
client: Lubdok
link: https://www.behance.net/gallery/...
color: #6c8cff
Analytics dashboard for a B2B SaaS product.
```

- `type`: ফিল্টার বাটনের নাম, যেমন Mobile app, Website, Dashboard, Landing page। না দিলে সাইট নিজে Mobile app, Website বা Web app বসায়।
- `link`: Behance, Figma prototype বা লাইভ সাইটের লিংক দিলে প্রজেক্ট পাতায় একটা বাটন আসবে।
- `color`: কার্ডের পেছনের আলোর রং। না দিলে সাইট নিজেই একটা রং বেছে নেয়।
- `key:` ছাড়া যেকোনো লাইন প্রজেক্টের এক লাইনের বর্ণনা হিসেবে দেখাবে। না দিলেও চলবে।
- কোনো ক্লায়েন্টের কাজ পাবলিক করা নিষেধ থাকলে সেই প্রজেক্ট আপলোড করবেন না।

## Figma থেকে export

1. ফ্রেমগুলো সিলেক্ট করুন। ডানদিকে **Export** অংশে **+** চাপুন।
2. ওয়েবসাইট আর ড্যাশবোর্ডের ফ্রেম: **1x, JPG**। 1440px চওড়া ফ্রেম 1440px-এই থাকবে।
3. মোবাইলের ফ্রেম: **2x, JPG**।
4. **Export** চাপুন। ফাইলের নাম ফ্রেমের নাম থেকে হয়, তাই আগে ফ্রেমের নাম দিন যেমন `01-home`, `02-cart`। "Frame 427318", "iPhone 14 - 3" এমন নাম থাকলে ক্যাপশন দেখাবে না, তবে অন্য সমস্যা নেই।

প্রতিটা ছবি ১MB-এর নিচে রাখার চেষ্টা করুন। খুব লম্বা ওয়েবসাইট পাতা বড় হলে https://squoosh.app দিয়ে ছোট করে নিন।

## আপলোড

1. GitHub-এ রেপোর `public/work/ui/` ফোল্ডারে যান।
2. **Add file → Upload files** চাপুন।
3. কম্পিউটার থেকে পুরো প্রজেক্ট ফোল্ডারটা (যেমন `02-Velvet-Store`) টেনে এনে ছেড়ে দিন, তারপর **Commit changes** চাপুন।

১-২ মিনিটের মধ্যে প্রজেক্টটা সাইটে চলে আসবে। প্রজেক্টের নিজের লিংকও থাকে, ক্লায়েন্টকে সরাসরি পাঠানো যায়:
`https://bappy-alpha.vercel.app/#ui/velvet-store`

একটাও প্রজেক্ট না থাকলে UI/UX সেকশন আর মেনুর "UI/UX" লিংক লুকিয়ে থাকে, তাই খালি সেকশন কখনো দেখাবে না।

Vercel → Deployments → সর্বশেষ deployment → **Build Logs**-এ `[ui] 4 projects, 37 screens` লাইনটা দেখলে বুঝবেন কয়টা প্রজেক্ট আর স্ক্রিন ধরা পড়েছে।
